# 湖北方言可视化项目文档

本目录记录项目现阶段已经确认的产品定位、首期范围、数据规范和后续扩展方向。

当前结论是：网站以湖北方言的记录、比较和传播为目的，《湖北省志·方言》只是参考文献之一；首期从书中第三部分“语汇”入手，将规则相对统一的词汇对照表整理为可检索、可比较、可追溯的数据，并通过地图和表格展示。

公众反馈和众包采集是保留功能，不纳入首期交付，但数据模型应提前为它留出空间。

## 当前优先级

1. 确定词汇数据录入及校对规范。
2. 录入四组、16 个有代表性的词汇概念作为样本。
3. 完成现行县级区划到原书调查地名的映射，并验证合并填色、四词小地图和原始表格。
4. 确认版权使用边界和地图数据许可证。
5. 样本验证通过后，再扩展到全部 148 个词汇概念。

## 地图配色约定

词目 JSON 只指定预设色系和色阶编号，不直接保存十六进制颜色。当前使用
`hubei-administrative-pastel-v1`：共 8 个色系，每个色系包含 4 个由浅到深的颜色，
实际颜色值固定在前端代码中。

```json
{
  "value": "爹",
  "family": 2,
  "color_index": 2
}
```

有词形关联的项目使用同一 `family`、不同 `color_index`，例如“爹”和“爹爹”可分别
使用色系 2 的第 2、3 号颜色。没有关联的词形优先使用不同色系；未配置项统一使用
`fallback` 颜色。这样既能表达词形之间的关系，也能避免数据文件任意注入颜色值。

## 暂不纳入首期

- 用户注册和登录。
- 在线投稿、点赞、审核后台。
- 录音上传与播放。
- 对整本书的全文数字化。
- 语音、语法两部分的完整录入。
- 将众包反馈自动合并为“标准答案”。
- 时间轴、年代切换和跨时期语言变化分析。
